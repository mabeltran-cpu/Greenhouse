# Greenhouse
Sistema con Arduino para solucionar la pérdida de cultivos por cambios bruscos de temperatura y humedad. Usa sensores (DHT11 y YL-69/FC-28) para monitorear en tiempo real, un servomotor que abre la ventilación por exceso de calor y LEDs de alerta visual. Una solución de tecnología integrada (hardware y software) autónoma y local.
